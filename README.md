# سوالات دوره آشنایی

یه صفحه ساده و ایستا برای سوال‌های دوره آشنایی پیش از ازدواج: ۷ جلسه، ۲۱۱ سوال، تم روشن و تاریک، تیک «پرسیده شد»، یادداشت برای هر سوال و جستجو.

## فایل‌ها

| فایل | کارش |
|---|---|
| `index.html` | صفحه اصلی |
| `style.css` | ظاهر صفحه و تم روشن/تاریک |
| `app.js` | تیک‌ها، یادداشت‌ها، جستجو و تغییر تم |
| `questions.js` | همه سوال‌ها و نکته‌ها. برای ویرایش سوال‌ها فقط همین فایل رو عوض کن. |

## انتشار روی GitHub Pages

1. توی گیت‌هاب یه مخزن (Repository) جدید بساز.
2. هر چهار فایل بالا رو توی ریشه مخزن آپلود کن (Add file ← Upload files).
3. برو به Settings ← Pages.
4. توی بخش Build and deployment، گزینه Source رو روی Deploy from a branch بذار، شاخه `main` و پوشه `/ (root)` رو انتخاب کن و Save رو بزن.
5. یکی دو دقیقه بعد، آدرس صفحه بالای همون بخش نشون داده می‌شه؛ چیزی مثل `https://USERNAME.github.io/REPO/`.

## چند نکته

- تیک‌ها و یادداشت‌ها فقط توی مرورگر همون دستگاه ذخیره می‌شن (localStorage). روی دستگاه دیگه دیده نمی‌شن و با پاک کردن اطلاعات مرورگر از بین می‌رن.
- توی حساب رایگان گیت‌هاب، GitHub Pages فقط برای مخزن عمومی فعاله؛ یعنی هر کسی آدرس رو داشته باشه سوال‌ها رو می‌بینه. یادداشت‌های تو هیچ‌وقت آپلود نمی‌شن.
- برای دیدن صفحه روی کامپیوتر خودت، کافیه `index.html` رو با مرورگر باز کنی.
- فونت‌ها (وزیرمتن و مرکزی) از Google Fonts لود می‌شن. اگه در دسترس نباشن، صفحه با فونت پیش‌فرض سیستم نمایش داده می‌شه.
- هر سوال توی `questions.js` یه `id` ثابت داره (مثل `"3-07"`). اگه `id` سوالی رو عوض کنی، تیک و یادداشت قبلی‌ش دیگه نمایش داده نمی‌شه. برای سوال جدید یه `id` تازه بذار.
- `see` یعنی این سوال، موضوع یه سوال از جلسه‌های قبل رو از زاویه دیگه می‌پرسه. توی صفحه با برچسب «مرور» نشون داده می‌شه.
